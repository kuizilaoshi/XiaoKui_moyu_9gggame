# XiaoKui_moyu_9gggame

30秒颜色反应挑战：适合短暂休息时玩的九宫格小游戏，采用复古冒险任务纸风格。

## 开始游戏

下载本仓库的 `index.html`，双击后使用浏览器打开。所有样式和逻辑都在同一个文件中，无需安装、联网或加载素材。电脑鼠标操作即可。

## 玩法

- 共 10 关，每关最多 30 秒；目标从 5 题逐关增加到 23 题，达标立即过关，失败可重试当前关。
- 前 6 关按格子中的文字选择，后 4 关随机切换“选文字”和“选底色”。先看题目要求；文字显示的颜色是干扰。
- 每题九种底色、九个颜色名称分别打乱，当前规则下只有一个正确答案。
- 答对加 1 分，答错显示正确答案；反馈期间锁定点击。
- 可从规则页或结算页打开“小窗口”。小窗口失去焦点时隐藏游戏并暂停计时，点击“继续显示”后恢复。浏览器可能需要允许弹出窗口。
